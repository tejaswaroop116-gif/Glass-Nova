====================================================================
  GLASS NOVA — SIMPLE WINDOWS 10 / 11 INSTALLATION GUIDE
====================================================================

Thank you for downloading Glass Nova!
No coding knowledge, Git, or manual terminal commands are required.


STEP 1: EXTRACT THIS ZIP FOLDER
-------------------------------
1. Right-click the downloaded ZIP file:
   GlassNova-Windows-Source-Launcher.zip
2. Click "Extract All..." and choose a normal folder
   (for example: Desktop\GlassNova or Documents\GlassNova).
3. Open the extracted "GlassNova" folder.

IMPORTANT: Do not double-click Start_Glass_Nova.bat from inside the
ZIP preview window — always extract first.


STEP 2: MAKE SURE PYTHON IS INSTALLED (ONE-TIME)
------------------------------------------------
Glass Nova runs using official Python (signed by the Python Software
Foundation), which avoids Windows 11 Smart App Control blocks.

If Python is not installed yet:
1. Download Python 3.12 (or 3.11) from:
   https://www.python.org/downloads/windows/
2. Run the Python installer.
3. CHECK the box at the bottom that says:
   [x] Add python.exe to PATH
4. Click "Install Now".


STEP 3: LAUNCH GLASS NOVA (ONE-CLICK)
-------------------------------------
1. Double-click:  Start_Glass_Nova.bat
2. On the very first run, it will automatically:
   - Create an isolated ".venv" folder inside GlassNova
   - Install the required packages (takes about 1-3 minutes;
     internet connection required for this first setup only)
   - Create a local ".env" file
   - Open Glass Nova
3. Every time you launch Glass Nova after that, it starts in seconds
   and works even without internet.


OPTIONAL: ENABLE ONLINE AI (GEMINI LIVE)
----------------------------------------
1. Get a Gemini API key from Google AI Studio.
2. Open the ".env" file inside the GlassNova folder with Notepad.
3. Paste your key after GEMINI_API_KEY= and save the file.
   Example:
   GEMINI_API_KEY=your_key_here
4. Restart Glass Nova.


OPTIONAL: ENABLE OFFLINE AI (OLLAMA)
------------------------------------
Basic offline commands (opening apps, volume, timers, notes, offline
Vosk voice, Windows SAPI speech) work immediately without Ollama.

For full offline AI chat and local screen vision:
1. Install Ollama from: https://ollama.com/download
2. Download recommended local models (in Command Prompt):
   ollama pull qwen2.5:3b
   ollama pull moondream
3. Pick your preferred models anytime inside Glass Nova:
   Settings -> Offline AI & Local Knowledge.


TROUBLESHOOTING
---------------
- "Python was not found": Install Python 3.12 from python.org and
  check "Add python.exe to PATH", then run Start_Glass_Nova.bat again.
- "Windows protected your PC" (SmartScreen on .bat): Click "More info"
  -> "Run anyway".
- Need help or found a bug? Report it at:
  https://github.com/tejaswaroop30/Glass-Nova/issues
