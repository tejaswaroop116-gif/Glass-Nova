Glass Nova

An AI-powered Windows desktop assistant featuring persistent Gemini Live voice and chat interaction, offline "Hey Nova" wake-word activation, verified Windows desktop automation, screen and document understanding, webcam hand-gesture mouse control, and animated desktop companions.

Core Capabilities

Gemini Live Voice & Chat

One persistent voice and text session with adaptive near-field barge-in, echo suppression, PyCAW media ducking, and a live microphone sensitivity HUD.

Offline Wake Word & Local Mode

Local Vosk "Hey Nova" wake-word listener and 0ms offline commands for apps, folders, volume, brightness, tabs, clipboard, tasks, memories, permissions, and companion controls.

Verified Desktop Automation

DPI-aware Windows UIAutomation with Gemini Vision fallback and structured verification so Nova confirms whether clicks, typing, tab closures, and YouTube controls succeeded.

Screen, PDF & Video Understanding

Permission-gated screen inspection, Point at Screen region selection (Ctrl+Shift+P), multi-page PDF/document analysis, and lecture/video frame explanation.

Fail-Closed Security & Workflows

9 separate permission categories, allow-listed action schema validation, destructive action confirmation, guided walkthroughs, and secret-free semantic workflow replay.

Companions & Hand Gestures

5 selectable always-on-top desktop companions (Original NOVA Robot, Ghost, Mummy, NOVA Painter Pet, Cloudy) plus optional webcam hand-gesture mouse control.

Quick Start on Windows

git clone https://github.com/tejaswaroop30/Glass-Nova.git
cd Glass-Nova
Start_Glass_Nova.bat

Add your GEMINI_API_KEY in .env for online Gemini Live voice and vision, or run immediately in Offline Local Mode without an API key.
