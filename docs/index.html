Hey Nova

Architecture Flow

How Glass Nova Works Safely

Every request flows through structured validation and a fail-closed permission layer before touching your desktop.

1

User Interaction

Speak with "Hey Nova", chat by text, or trigger a global shortcut.

2

Nova AI & Router

Gemini Live or the 0ms offline matcher selects an allow-listed action.

3

Permission Check

Fail-closed check verifies session grant or prompts Allow Once / Deny.

4

Action

ApprovedActionBroker runs the validated tool via UIAutomation or Win32.

5

Verified Feedback

Nova checks the outcome and replies honestly with confirmed or failed status.

Safety guarantee: Sensitive actions — including screen viewing, continuous observation, mouse & keyboard control, file modification, and file deletion — require explicit user permission. If permission is denied or cannot be verified, the action stops immediately.
Trust & Compatibility

Fail-Closed Privacy & System Requirements

9 Separate Permission Categories

Grant only what you need, revoke anytime by button or voice, and see active visual badges whenever screen or control access is running.

screen_view continuous_screen (always prompt) document_access media_access mouse_keyboard file_modify file_delete (always prompt) app_install form_purchase (always prompt)
  • Fail-closed by default: missing callbacks never silently grant access.
  • Workflow recorder strips secrets and rejects raw keystrokes or clipboard capture.
  • Tasks, memories, and audit logs stay locally under %APPDATA%\PC_Complete_Assistant\.

Requirements & Compatibility

  • Operating System: Windows 10 or Windows 11 (uses native Win32, UIAutomation, PyCAW, and SAPI APIs).
  • Python: Python 3.11 or 3.12 (recommended).
  • Gemini API Key: Required for online Gemini Live voice, chat, and vision. Leave blank to use Offline Local Mode immediately.
  • Optional Hardware: Microphone & speakers for voice/wake word; webcam for hand-gesture mouse control.
  • Automated CI: Verified on Windows via 6 test suites (security audit, feature pack, screen interaction, integration, pipeline, and website checks).
Quick Start

Install & Launch on Windows

Clone the repository and run Start_Glass_Nova.bat to create .venv, install requirements.txt, copy .env.example, and launch Glass Nova.

Windows Command Prompt / PowerShell 
git clone https://github.com/tejaswaroop30/Glass-Nova.git
cd Glass-Nova
Start_Glass_Nova.bat

Add your GEMINI_API_KEY in .env for online Gemini Live voice & vision, or start right away in Offline Local Mode. You can also package a standalone Windows executable with python build_exe.py.

FAQ

Frequently Asked Questions

Does Glass Nova work without a Gemini API key?

Yes. Offline Local Mode handles common Windows actions locally with 0ms latency — opening and closing apps or folders, volume and brightness control, window and browser tab actions, clipboard, screenshots, system status, local tasks and memories, calculator math, companion controls, hand gestures, and permission commands.

Does Glass Nova watch my screen in the background?

No. Screen viewing and continuous observation require explicit screen_view or continuous_screen permission, and an active indicator badge appears in the top bar whenever screen observation is running.

Which operating systems are supported?

Glass Nova is built specifically for Windows 10 and Windows 11 because it integrates directly with native Windows UIAutomation, Win32 APIs, PyCAW audio ducking, and Windows SAPI offline speech.

How do I customize or contribute to Glass Nova?

Check the Contributing Guide on GitHub. All 6 automated test suites run locally and on GitHub Actions.
