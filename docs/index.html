Security & User Control

Explicit Permission Before Sensitive Actions

Glass Nova never silently controls your mouse, modifies files, or monitors your screen. Every sensitive request shows the exact category and action first.

Actual Glass Nova Permission Dialog — Mouse & Keyboard Control request

Action-Specific, Fail-Closed Approvals

When an action requires elevated access, Nova displays the exact category and target action — and lets you respond by click or hands-free voice ("Allow", "Allow Once", or "Deny").

Allow for Session Grants the category until you revoke or exit.
Allow Once Approves only this single requested action.
Deny Immediately stops the action without executing.

  • Fail-closed by default: if permission cannot be verified, protected tools deny automatically.

How Nova Works

Transparent Execution From Request to Verified Result

Whether you speak online with Gemini Live or run a local offline command, Glass Nova validates and verifies every step.

1

User Request

Say "Hey Nova", talk in voice chat, type a message, or use a shortcut.

2

AI Processing

Gemini Live or the 0ms offline matcher maps the request to an allow-listed schema.

3

Permission Check

When required, Nova checks session grants or asks Allow Once / Session / Deny.

4

Action

ApprovedActionBroker runs the validated tool via UIAutomation or Windows APIs.

5

Verified Feedback

Nova checks the actual outcome and replies honestly with confirmed or failed status.

FAQ

Frequently Asked Questions

What is Glass Nova?

Glass Nova is a Python and PySide6 AI desktop assistant for Windows 10/11 combining Gemini Live voice and chat, offline "Hey Nova" wake-word activation, verified desktop automation, screen/PDF/video understanding, hand-gesture mouse control, and animated companions.

Is Glass Nova free?

The Glass Nova software is free to download and run locally from GitHub. Online Gemini Live and vision features use your own Google Gemini API key (subject to Google's API quota/pricing), while Offline Local Mode runs completely free on your PC.

Does Nova work offline?

Yes. Offline Local Mode handles common Windows actions locally with 0ms latency — opening/closing apps and folders, volume and brightness, window/tab controls, clipboard, screenshots, system status, tasks, memories, calculator math, companion controls, hand gestures, and permission commands.

Does Nova require an API key?

No API key is required for Offline Local Mode. Adding GEMINI_API_KEY in .env unlocks online Gemini Live voice conversations, open-ended Q&A, and AI vision analysis.

How does the permission system work?

Glass Nova uses a fail-closed permission manager with 9 separate categories. Sensitive actions prompt you with the exact category and target action, allowing Allow Once, Allow for Session, or Deny by click or voice.

Which Windows versions are supported?

Windows 10 and Windows 11 are supported. macOS and Linux are not supported because Glass Nova relies on native Win32, Windows UIAutomation, PyCAW, and SAPI APIs.

How do I install Nova?

Clone https://github.com/tejaswaroop30/Glass-Nova.git and run Start_Glass_Nova.bat, which automatically sets up the Python virtual environment, installs dependencies, and starts the app.

What features require an internet connection?

Gemini Live voice/chat conversations, general AI Q&A, web searches, and Gemini Vision screen/PDF/video explanations require internet access and a valid Gemini API key. Local system commands and Vosk wake-word detection work offline (after the one-time Vosk model download).
