02 Modes & Voice

Cloud speed when connected. Local autonomy when offline.

Switch cleanly between Online, Offline, and Hybrid modes. Every requirement and limitation below matches the actual repository implementation.

Voice / Chat→ Gemini Live (Ordered Model Fallback)→ Permission Gate→ Windows & Browser Tools

Gemini Live Native Audio & Full Tool Access

  • Ordered Model Fallback: Connects to gemini-2.5-flash-native-audio-preview with configured fallbacks and reports connection status instead of switching silently.
  • Multimodal Intelligence: Live web search, screen inspection, Point at Screen, document/PDF Q&A, and video keyframe analysis.
  • Verified Automation: Windows UIAutomation actions, Playwright browser tasks, guided walkthroughs, and reusable semantic workflows.

What Online Mode Requires

  • Internet + API Key: Requires internet and your own GEMINI_API_KEY in local .env.
  • Cloud Processing: Prompts, audio, and triggered screen frames are sent to the Google Gemini API.
Vosk Offline Voice / Chat→ 0 ms Local Commands OR Local Ollama→ Windows SAPI Offline TTS

Zero-Internet Commands, Local Voice & Optional Ollama AI

  • 0 ms Deterministic Commands: Launch apps, control volume/brightness/media, manage windows, timers, reminders, notes, clipboard, calculator, and local file search.
  • Offline Voice & Speech: Unconstrained Vosk offline speech recognition paired with live-verified Windows SAPI TTS (comtypes/win32com).
  • Optional Local Ollama AI: Adds local chat, bounded 5-step OfflineAgent (qwen2.5:3b), local screen/video vision (moondream), and offline guided walkthroughs.

What Offline Mode Requires

  • Zero Internet Needed: Deterministic commands, Vosk voice, SAPI TTS, Safe Python, and TF-IDF Local Knowledge work completely offline.
  • Optional Ollama Models: Pull qwen2.5:3b and moondream for local AI reasoning and vision.
  • Unavailable Offline: Live web search and Gemini Live cloud audio require internet.
Local 0 ms Reflexes+ Cloud Gemini Live (Online)↔ Local Ollama & SAPI Continuity (Offline)

Local-First Speed with Cloud Intelligence on Demand

  • Fast Local Reflexes: Everyday Windows actions run locally while complex queries use Gemini Live when online.
  • Consistent Audio State: Mic Listening, Spoken Replies, and Text Mode Lock stay synchronized across all mode switches.
  • Graceful Continuity: If internet drops, local commands, offline SAPI speech, and Ollama remain ready.

Recommended Hybrid Setup

  • Optional Dual Stack: Add GEMINI_API_KEY for cloud features and Ollama for full offline AI continuity.
  • Manual Control: Switch modes explicitly anytime without losing your voice or text lock preferences.

    06 Privacy & Control

    Fail-closed permissions that AI models cannot self-grant.

    AI tools can only check status or revoke permissions — never grant them. Tap any of the 9 categories to inspect its rule:

    screen_view: Required before any single-frame screenshot or visual screen inspection in both Online and Offline modes.
    Honest Privacy Disclosure: In Online Mode, prompts, voice audio, and triggered screen captures are sent to the Google Gemini API. Local settings, history, and permission states are stored in %LOCALAPPDATA%\GlassNova as plaintext JSON with secret redaction — Windows DPAPI encryption is not yet implemented.

    07 Setup & Status

    Honest requirements, transparent status, open source on GitHub.

    Start_Glass_Nova.bat sets up the virtual environment and installs missing dependencies only when needed — subsequent launches start fast, even offline.

    Verified Requirements

    • OS: Windows 10 or Windows 11 (64-bit).
    • Python: Python 3.11 or 3.12 recommended for PySide6 & Vosk compatibility.
    • Online Mode (Optional): Internet + your own GEMINI_API_KEY.
    • Offline AI (Optional): Local Ollama with qwen2.5:3b & moondream. Reference tested hardware for local models: Intel i5-12450H, 16 GB RAM, RTX 3050 (4 GB VRAM).

    Current Limitations (Active Development)

    • Source Install Today: No signed .exe installer release yet — run via Start_Glass_Nova.bat or build locally with build_exe.py.
    • Settings UI Gaps: Graphical pickers for Ollama models and Local Knowledge folders are not yet built — configure via .env or chat commands.
    • Local Storage: Redacted plaintext JSON in %LOCALAPPDATA%\GlassNova (Windows DPAPI encryption is planned).
    • Windows-Only: Relies on Windows UIAutomation, SAPI TTS, and Win32 APIs.
    PowerShell — Clone & Launch Glass Nova 
    # 1. Clone the repository
git clone https://github.com/tejaswaroop30/Glass-Nova.git
cd Glass-Nova

# 2. Launch Glass Nova (creates .venv on first run; fast launch afterwards)
.\Start_Glass_Nova.bat

# 3. Optional: enable Offline AI reasoning & local screen vision via Ollama
ollama pull qwen2.5:3b
ollama pull moondream
